# Security Policy

## Supported versions

| Version | Supported |
|---------|-----------|
| 0.1.x   | Yes       |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report vulnerabilities privately:

1. Go to the [Security tab](https://github.com/MathiasPaulenko/selenium-expect/security/advisories/new) on GitHub.
2. Click **"Report a vulnerability"**.
3. Describe the issue, including steps to reproduce and potential impact.

You will receive a response within 72 hours. If the vulnerability is confirmed, a fix will be prioritized and a GitHub Security Advisory will be published.
